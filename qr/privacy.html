This Privacy Policy explains how QR Code generator free (the “Extension”) collects, uses, and protects information. By installing or using the Extension, you agree to the practices described here.

1. Information We Collect

Active Tab Access (activeTab permission):

We temporarily access the content of the currently active browser tab only when you click the extension icon (or otherwise interact with the extension in a way that grants access). This access is used to provide features such as analyzing page content, capturing the URL, or injecting scripts/styles needed for the requested action. We do not monitor or track your browsing activity in the background.

Local Storage (storage permission):

We store limited data such as user preferences, configuration options, or session state using Chrome’s storage. Stored data remains on your device unless you explicitly choose an option that syncs or shares data externally. We do not collect personal or sensitive information by default.

2. How We Use Information

  • To deliver the core functionality of the Extension (for example: analyze the active page when requested, inject UI into the page, or capture a page URL for processing).
  • To remember your preferences and settings across browser sessions (theme, toggles, last-used options).

3. Data Sharing & Third Parties

We do not sell, rent, or trade your personal information. By default, the Extension does not send page content, URLs, or stored preferences to third-party services.

If the Extension includes optional features that send data to external services (for example, to sync across devices or to use an external API), those features will be clearly disclosed in the extension UI and require your explicit consent.

4. Data Security

We use Chrome’s storage APIs and follow best practices to limit stored data to non-sensitive preferences. Because most data is stored locally, risk is minimized. However, no method of storage or transmission is completely secure — please avoid storing sensitive personal data in extension storage.

5. Your Choices

  • You can uninstall or disable the Extension at any time via Chrome’s Extensions page.
  • You can clear extension data by removing stored items in Chrome’s extension storage (via DevTools or browser settings) or by choosing any “Clear data” control provided in the Extension UI, if available.
  • Optional features that share data externally will require explicit opt-in; you can revoke consent by disabling those features.
